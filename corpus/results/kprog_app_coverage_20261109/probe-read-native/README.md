# Native P protected probe-read candidate

The native-only helper wrapper lowers constant1/2/4/8byte kernel reads to one REP MOVS element at the same access width. Existing exception recovery skips a faulting element and clears its destination. Success uses source advancement together with zero remaining count; this distinguishes legitimate zero data and wrapped source addresses from faults. Failure clears the complete destination and returns-EFAULT. Existing x86 maccess address eligibility routes user/vsyscall addresses through the original helper; other sizes retain their original call. Kernel after-verification code and submitted P bytes retain their definitions.

Both complete3object Tracee payloads use the same current source, flags and division plugin. The control reads its header from a read-only committed export in a private mount namespace; the candidate uses the master edit. The original Tracee C/JIT source retains its paired09f40 definition. summary.json records every object/hash/REP site and full manifest count; payload.tar.gz carries both complete manifests, all objects, command/build/disassembly logs and plugin. Actual fault and application work replays remain separate from compiler observations.
