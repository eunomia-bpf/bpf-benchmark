# Canonical simulator C headers

These headers are checked-in C sources, edited directly since M4. The directory
name preserves the simulator’s existing include paths. Their historical JSON
inputs, Python renderers and generated Lean contracts were removed by the
2026-11-16 legacy retirement; they are no longer a second implementation or
proof route. Clight exports come from these same C bodies through the formal
build. Their historical origin comments do not imply regeneration.
