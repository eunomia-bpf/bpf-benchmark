# Original caller remaining fixed header source and layout

The exact sixteen original assignments after vector-pointer NULL initialization retain their original RHS expressions. Reconstructed source, source shapes, fifteen successor equalities and the following original nested _i=0/Sloop source are kernel checked.

The actual header composite has size728. The first six pointer fields occupy offsets608..648; three uint fields occupy656,660,664; bias occupies672; six remaining pointers occupy680..720. Actual field types, offsets and Mint32/Mint64 chunk sizes are checked against that composite. The same original Header witness supplies writable bytes608..727, and actual original field-lvalue evaluation derives each target address.

Nine root queries check source, first_source, shape, chain, loop_start, layout, offsets, storage and target_locations. Direct, focused, full-root and public logs are retained.

This step does not derive RHS values/casts, actual stores, sequential visits or loop execution. Those must use the original stack/payload/tag/local bindings and actual callback global symbols and preserve the preceding76 pointer-field reads within the same header block. First LINK, native/global/universal refinement and M6 remain open.
