# Actual caller NZCV input sites and byte stores

The module extracts all four original call/mask/store statements from the
actual successor of the 62 pointer-table initializers. Kernel checks match
each whole statement against the mature FlagDeclaration schema, its real
callee/types/temporary/local/successor; prove N/Z/C/V names, actual local
membership and separation; and bind the chain to the actual following LR
zero assignment and vector source. It does not regenerate the captured AST.

Each visit derives an actual byte-local binding and current write permission
from the SAME original 795-local allocation. Its actual store reads back the
masked low bit, proved zero or one, and frames every other memory block,
old caller memory, access and allocation frontier. No successful reader or
store premise supplies this construction, and no old producer heap or
allocator is identified with the actual caller.

The existing generic flag_call_body and flag_return_body execute the actual
three-step call prefix and four-step return/store suffix with the actual
caller function, environment and callee. input_returns composes those once
around an explicit actual CompCert external call, retaining its exact trace,
return value and supplied heap. Provider effects and current access remain
explicit. This is a per-visit result for each of the four actual source sites;
all-four sequential execution, earlier observers across provider effects and
entry composition remain subsequent work.

The LR/vector boundary is a source certificate, not an execution claim.
Native execution, loaded-text equivalence, whole Clight refinement,
universality and fixture/resource recount remain open. Actual Cilium LINKs
remain BPF-helper calls, separate from memcpy. Source hashes, original
resource caps, timing policy and full checks are in validation.json; public
types and actual axioms are checked by Query.lean. The promoted source is
byte-identical to the successful direct-check snapshot.
