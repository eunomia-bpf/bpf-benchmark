# Captured x86 and ARM Cilium source comparison

This reads the x86 `checked-corpus-20261126-qm` run associated with a55ba238d (64 requests, 35 checked) and the latest ARM run 20261127T120527Z (17 requests before the frozen 900-second timeout). No compiler or guest was launched for this comparison; CPU19 performed metadata/archive work while the full scalar-memory corpus used CPUs16/18.

All 17 ARM requests match an x86 entry name and program type. Only ARM request8 `cil_host_policy` also matches every map binding and shape (x86 requests8/44/62); both have three native instruction labels and C sizes714/670 bytes. The other16 entries have different map bindings, including additional ARM `__config_*` aliases and runtime maps. They are related entries, not identical captured native inputs. `pairs.tsv` preserves every candidate request group rather than guessing one-to-one identities.

After removing only the exact obsolete75-macro profile from the captured ARM C, median ARM/x86 C size is2.14049x and median native-label count is1.63573x across the17 entry groups. These ratios include differences in the native inputs and do not isolate generator cost. For `cil_xdp_entry`, ARM37,573 bytes/205labels versus x8611,493/75; ARM additionally names `__config_enable_xdp_prefilter`, `__config_tracing_ip_option_type` and `cilium_percpu_trace_id`. For `cil_to_host`, ARM122,634/667 versus x86 median13,359/80, with16 additional ARM map/config names.

Captured x86 frontend commands compile preprocessed `.i` with the common x86 `-O1` flags; ARM compiles C directly with its common `-O2` flags. C byte counts exclude macro expansion. ARM has17 broker receipts with frontend wall/RSS, totaling463.206 frontend seconds; x86 has no per-frontend timing receipt, so its frontend values stay null. Summed complete request intervals are524.560s for all64 x86 requests and874.307s for the17 ARM requests; those include preprocessing/linking/verification/native compilation and come from different guest configurations. They must not be presented as frontend speedup.
