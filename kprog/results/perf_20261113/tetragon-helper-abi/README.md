The current Tetragon compatibility header emits inline-asm calls whose RDI/RSI/RDX/RCX/R8 argument operands are input-only. Those same registers are omitted from the clobber list. Clang therefore assumes they survive the helper call, while real SysV helpers and the native LTO routines may overwrite them. The original event_execve object at0x327/0x344 and cwd_read_v61 show arguments reused without reloads. The console panic in tetragon-native-console/panic.txt is a downstream unbounded probe-read copy in event_execve.
