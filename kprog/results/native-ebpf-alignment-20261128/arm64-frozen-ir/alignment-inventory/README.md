Each program row records the six requested alignment dimensions and the concrete runtime evidence still needed. A staged declaration is not a load/install event.

Every object has frontend IR and the expected ISA. No flags or tuning are changed.

These are recorded candidates, not loader failures: native_loader_manifest.hpp653 leaves an unspecified symbol empty, and native_loader_trusted.cpp3170-3178 obtains the original program BTF symbol. The next dynamic join must use full symbol/object/program-ID/load-plan facts. Do not select a prefix match arbitrarily or add a per-program configuration. The corrected census retains trace_vfs_write/trace_vfs_writev and filter_char_buf/equal/postfix/prefix siblings when the manifest leaves its symbol unspecified. Map-name collision groups are likewise declarations, not proof that a wrong live map was bound; the normal name/ID/type/shape resolution and generic handling remain authoritative.

Read-only native sections are candidate data only. Freeze requires the actual loaded data map facts and app-written value; neither immutable content nor eliminated branches are inferred from .rodata. Direct entry relocations omit resolved intra-section calls, transitive calls, optimizer effects and code patched later, so a missing relocation does not prove a helper or tail path absent. Actual baseline/native installed code and work evidence must finish the comparison.
