# ARM frozen-global runtime work check

One existing frozen one-image-arm64 corpus functional cell: OTel, one10-second sample, stats on, Cortex-A57/four vCPUs/eightGiB, on CPUs16-19 under the image lock. The successful component, image and root builds are reused. The recorded dry-run shows root creation is up to date and no rebuild is invoked. Benchmark/workload/framework/P flags are unchanged. This is a functional diagnostic, not a timing result.

A separate read-only process starts beside the original init via a cached-root wrapper, then the exact original init and frozen corpus entry run unchanged. The original init bytes are restored on controller exit. Observation code only calls BPF enumeration/info/map lookup, reads proc/sysfs, and copies actual link-cache files into evidence; it never selects, disables, reconfigures or counts as acceptance for a program. Architecture syscall selection is from the actual uname and checked against the current kernel UAPI; the actual ARM P DWARF is retained for later record decoding. No production/framework source edits or new app switches.

Snapshots preserve all program statistics plus OTel perf_progs/metrics/per_cpu_records/mapping lookups; real code dumps target entry/native unwind/stop on program-ID or JIT-size changes. These sparse observations are non-atomic, can miss a short phase, and may fail independently of the workload. Code/work equality requires manual phase-matched review of actual installs, frozen values/removed calls, unwind attempts/frames, nonzero stacks and tail targets; exit0 or a ratio alone is insufficient. Partial snapshots and failures are retained. No automatic rerun, callback publication, RAW deletion, PMU or tuning.

The controller preserves guest output, observations/link cache and complete newly copied corpus results in persistent RAW, records all file SHA/size, and archives them after exit. Manual collection verifies the archive and results before publication. The cached-root perf-observe directory remains another raw copy until a later archive/Git/full-file verified dedup; preserve it before any future root rebuild. This run uses the common ARM compiler/linker/loader and image b278 already delivered, not the stopped checked-path replay.

The operator48GiB compiler address-space cap is inherited inside the8GiB guest via the init wrapper; host QEMU/controller retain their original unlimited address space. This is the requested build resource bound, not a benchmark setting or a new production guard. One app loads serially through the common loader, with at most the native compiler and its helper-C compiler active; no concurrent build job is started.
