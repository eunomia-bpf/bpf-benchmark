# Retained experiment records

These are completed F experiment records retained during the operator-ordered
cleanup. Per-form TSVs, outcome JSON and logs retain their measured outcomes;
this archival step makes no additional correctness claim. Counterexamples are
lossless gzip streams. Rebuildable reference executables and raw CPU traces
are removed only after publication. See `../../cleanup/README.md` and its
retention manifest for file hashes and deletion provenance.
