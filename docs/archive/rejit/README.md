proposals, pass studies, and dated experiment records. The
[current design](../../rejit-speculative-optimization-ebpf_idea.md) and
[current evaluation](../../evaluation.md) describe the stock-kernel shim and
two-start load-time corpus protocol.

The [build-and-evaluate records](build-and-evaluate/) contain the dated step
reports cited by the evaluation. See [MOVED.md](../../MOVED.md) for the full
path mapping.
