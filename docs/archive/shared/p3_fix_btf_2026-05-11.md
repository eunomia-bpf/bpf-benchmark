# P3 BTF Remap Fix - 2026-05-11

## Diagnosis

Actual bug: `bpfopt/crates/bpfopt/src/analysis/bbprogram.rs:791`, in
`BBProgram::rebuild_use_def_after_mutation`.

Before this patch, the method ended by calling `reset_btf_to_current_pcs()`.
That rebuilt `self.btf` from current lowered PCs after every mutation, erasing
the original-PC identity stored as the BTF metadata value. Deletion then
recreated a mapping for the deleted original PC, and shortening replacements
dropped original records whose old PC no longer existed as a current PC.

## Patch

Removed the BTF reset from the mutation rebuild path and removed the now-unused
private helper. Instruction and block mutation APIs already update `self.btf`
with `shift_metadata_after_delete`, `shift_metadata_after_insert`, and
`remap_metadata_sites`, preserving the current-site to original-PC mapping that
`remap_btf_records_view` and lowering require.
