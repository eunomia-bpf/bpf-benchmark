# Shared framework archive

This directory retains dated runner, corpus, microbenchmark, build, and
cross-project research notes. The current [shared design](../../shared/design.md)
and [results guide](../../shared/evaluation.md) point to supported entrypoints
and raw datasets. Historical notes may describe removed apps, binaries, or
experiment protocols; they remain here to preserve provenance.

The dated folders hold step reports and investigations. The `active/` and
`archived/` folder names are inherited from the former `docs/tmp/` tree and
are historical labels. See [MOVED.md](../../MOVED.md) for every original path.
The [source optimization records](source-opt/README.md) retain the dated
per-application attempts and their result references.
