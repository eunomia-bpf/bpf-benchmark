# V4c fix cleanup report (2026-05-12)

## Scope

Implemented review §2/§3 cleanup for `bpfopt` without changing pass policy:

- removed `map_inline.rs` single-caller wrappers / veto-only helpers by inlining their checks at the only call site
- merged `bbprogram_api.rs` replacement APIs into one bool-returning core
- narrowed `insn.rs` production API surface by deleting one-caller helpers or making test-only constructors `#[cfg(test)]`
- moved `BBProgram` single-caller conveniences to pass-local/shared helpers
- deduplicated cross-pass condition inversion, checked skip construction, reverse body deletion, and frame-local site scans in `pass.rs`
