## Edge Cases

- `cond_select` still uses `replace_diamond_with_insns`; the old admission helper was replaced with a direct `admission_skip_reason` check before the diamond rewrite.
- `ccmp` needs a direct pre-validation `admission_skip_reason` check so cross-subprogram chains report a skip before CFG validation. The final body replacement runs through `try_replace_range_with_skips` on a transaction clone.
- `map_inline` keeps terminator edits on the terminator API and routes body replacements/deletions through `try_replace_range_with_skips`; skipped body edits abort the cloned edit batch instead of partially rewriting the program.
- Release build exposed two compile-only issues in already-migrated files: `rotate` needed the live-out set computed before the replacement closure, and `skb_load_bytes` needed mutable scan state plus insert/delete expansion to preserve its no-admission 1->N helper rewrite behavior.
