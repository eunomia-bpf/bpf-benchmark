## 2. Deletion Rationale

`pass_tests.rs`: deleted `AnalysisCache`, typed `Analysis`, dummy pass-manager
invalidations, and legacy result-name mechanics. The retained tests now specify
the future contract: a lifted `BBProgram` is shared by multiple passes, lowered
once, with verifier/map/profile side inputs on `PassContext`.

`branch_flip_tests.rs`: deleted scanner-only diamond fixtures and direct helper
roundtrips. Kept pass-path behavior that would catch real paper-B regressions:
missing program/site PMU data, bias/miss gates, oversized branch overflow, and
multi-site layout preservation.

`endian_tests.rs`, `extract_tests.rs`, and `rotate_tests.rs`: deleted scan/emit
matrix tests that only exercised pass-private helpers or synthetic happy paths.
Kept end-to-end BBProgram pass specs for the important edge cases: provenance
requirements, branch-target safety, module call offsets, per-size kinsn targets,
subprogram frames, and live-out constraints.

`map_inline_tests.rs`: deleted helper-only key extraction/classification tests
and toy map fixtures. Kept the fail-fast and side-input behavior called out by
the review: hard/soft hints, verifier-state invalidation, missing/skipped
snapshots, compressed overlays, per-CPU/mutable skips, and map-in-map route A.

`bounds_check_merge_unit.rs`: deleted because it duplicated the in-module
`bounds_check_merge_tests.rs` coverage.
