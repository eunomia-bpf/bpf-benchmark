## Fix

`KinsnDescriptor` now carries a `register_uses: fn(payload: u64) -> RegSet`
hook. All seven kinsn passes implement it from their packed sidecar payloads:

- `rotate`
- `cond_select`
- `ccmp`
- `extract`
- `endian_fusion`
- `bulk_memory`
- `prefetch`

`LivenessAnalysis` now has a kinsn-aware entry point:

```rust
LivenessAnalysis::run_with_kinsn_registry(program, registry)
```

When it sees a packed `sidecar + call_kinsn` pair, it:

1. validates the sidecar/call shape,
2. resolves `(btf_id, call_off)` through `KinsnRegistry`,
3. validates the payload with the descriptor proof decoder,
4. replaces the generic helper-call ABI model with descriptor-provided
   register uses,
5. clears the pseudo-sidecar's synthetic `MOV imm` def.

`DcePass` now invokes this kinsn-aware liveness path through the existing
`PassContext`. The DCE deletion predicate remains unchanged.

## Regression

Added `passes::dce_tests::dce_preserves_kinsn_implicit_register_uses`.

The fixture encodes the decisive OTEL shape:

```text
r6 = 0
r0 = 1
r1 = cond
sidecar payload 0x1066
call bpf_select64
```

The test proves DCE preserves the `r6` and `r0` materialization consumed through
the `cond_select` sidecar payload.
