## Defect-1/2 Review

Pass:

- `analysis/branch_target.rs` uses `insn.branch_target_pc(pc)` for normal branches, so JA32 is decoded through `imm`.
- `analysis/cfg.rs` uses `branch_target_pc` in block start and edge construction.
- `rewrite.rs::fixup_all_branches` returns `anyhow::Result<()>` and calls `set_branch_target_delta`, which fails if off16/i32 cannot represent the new delta.
- `branch_flip` uses `set_branch_target_delta` on its generated JCC/JA offsets.

Weakness:

- `branch_flip_tests::test_branch_flip_rejects_oversized_manual_branch_delta` only calls `checked_off16(40_000, ...)`; it does not run `BranchFlipPass` on a program whose transformed JCC/JA delta exceeds the range. Reverting the actual run-path conversion could avoid this test if the helper remains.
